# F0 — Fundação — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar o monorepo com banco multi-tenant protegido por RLS, esqueleto da API e da PWA, outbox e CI, sobre o qual todas as fases seguintes constroem.

**Architecture:** Monorepo pnpm com `apps/api` (Fastify + Kysely sobre PostgreSQL), `apps/web` (React + Vite PWA) e `packages/contracts` (schemas zod). Migrações em SQL puro aplicadas por um runner próprio. Todo acesso ao banco passa por `withTenant`, que define `app.school_id` na transação; as políticas RLS usam esse valor.

**Tech Stack:** Node 22, pnpm, TypeScript, Fastify, Kysely, pg, zod, Vitest, Testcontainers, React, Vite, vite-plugin-pwa, tsup, ESLint.

**Spec:** `docs/superpowers/specs/2026-11-16-app-lanche-design.md` (seções 3, 4.4, 6.1, 6.3, 9, 11, 12, 13). Leia também o `CLAUDE.md` da raiz.

## Global Constraints

- Requisitos de máquina: Node >= 22, pnpm, Docker em execução (os testes da API sobem PostgreSQL em container).
- Instale dependências com `pnpm add` (sem fixar versão à mão); o lockfile fixa.
- TypeScript estrito; ESM (`"type": "module"`); resolução `Bundler` (imports sem extensão).
- Banco em `snake_case`, código em `camelCase` (Kysely `CamelCasePlugin`).
- Ids: UUID v7 gerado na aplicação (`uuidv7()` do pacote `uuidv7`).
- Toda tabela exceto `schools` e `schema_migrations`: `school_id uuid NOT NULL`, política RLS `tenant_isolation`, `UNIQUE (school_id, id)`, FKs compostas.
- Políticas RLS usam a função `app_school_id()`, nunca `current_setting` direto.
- A aplicação conecta como `app_user` (sem `BYPASSRLS`, não é dona das tabelas). Migrações rodam com o usuário administrador.
- Migração aplicada nunca é editada.
- SQL só em `repo.ts` e em `apps/api/src/db`. Testes podem usar SQL direto.
- Sem mock de banco.
- Nunca registrar em log telefone, e-mail, nome, token, OTP ou corpo de requisição.
- Código, nomes e commits em inglês; texto de interface em português do Brasil.
- Todo commit termina com as linhas de atribuição usadas no repositório.

`db/migrate.ts`:
```ts
import { readdir, readFile } from "node:fs/promises";
import path from "node:path";
import { fileURLToPath } from "node:url";
import pg from "pg";

const MIGRATIONS_DIR = path.join(path.dirname(fileURLToPath(import.meta.url)), "migrations");

export async function migrate(opts: { adminUrl: string; appPassword: string }): Promise<string[]> {
  const client = new pg.Client({ connectionString: opts.adminUrl });
  await client.connect();
  try {
    await client.query("SELECT pg_advisory_lock(727001)");
    await client.query(`
      DO $$ BEGIN
        IF NOT EXISTS (SELECT 1 FROM pg_roles WHERE rolname = 'app_user') THEN
          CREATE ROLE app_user LOGIN;
        END IF;
      END $$`);
    await client.query(`ALTER ROLE app_user PASSWORD ${client.escapeLiteral(opts.appPassword)}`);
    await client.query(`
      CREATE TABLE IF NOT EXISTS schema_migrations (
        name text PRIMARY KEY,
        applied_at timestamptz NOT NULL DEFAULT now()
      )`);
    const done = new Set(
      (await client.query<{ name: string }>("SELECT name FROM schema_migrations")).rows.map(
        (r) => r.name,
      ),
    );
    const files = (await readdir(MIGRATIONS_DIR)).filter((f) => f.endsWith(".sql")).sort();
    const applied: string[] = [];
    for (const file of files) {
      if (done.has(file)) continue;
      const sqlText = await readFile(path.join(MIGRATIONS_DIR, file), "utf8");
      await client.query("BEGIN");
      try {
        await client.query(sqlText);
        await client.query("INSERT INTO schema_migrations (name) VALUES ($1)", [file]);
        await client.query("COMMIT");
      } catch (err) {
        await client.query("ROLLBACK");
        throw new Error(`migration ${file} failed: ${(err as Error).message}`);
      }
      applied.push(file);
    }
    return applied;
  } finally {
    await client.end();
  }
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const adminUrl = process.env.DATABASE_ADMIN_URL;
  const appPassword = process.env.APP_DB_PASSWORD;
  if (!adminUrl || !appPassword) {
    console.error("DATABASE_ADMIN_URL and APP_DB_PASSWORD are required");
    process.exit(1);
  }
  migrate({ adminUrl, appPassword }).then(
    (applied) => console.log(applied.length ? `applied: ${applied.join(", ")}` : "up to date"),
    (err) => {
      console.error(err);
      process.exit(1);
    },
  );
}
```

`db/migrations/0001_schools.sql`:
```sql
-- Depois de um SET LOCAL, o parâmetro volta como string vazia na mesma sessão;
-- nullif evita o erro de cast e faz a política não casar com nenhuma linha.
CREATE FUNCTION app_school_id() RETURNS uuid
LANGUAGE sql STABLE
AS $$ SELECT nullif(current_setting('app.school_id', true), '')::uuid $$;

CREATE TABLE schools (
  id uuid PRIMARY KEY,
  name text NOT NULL,
  timezone text NOT NULL DEFAULT 'America/Sao_Paulo',
  default_cutoff_time time NOT NULL DEFAULT '07:30',
  kitchen_phone text,
  payment_account_ref text,
  payment_webhook_secret_ref text,
  platform_fee_bps integer NOT NULL DEFAULT 0 CHECK (platform_fee_bps BETWEEN 0 AND 10000),
  created_at timestamptz NOT NULL DEFAULT now()
);

ALTER TABLE schools ENABLE ROW LEVEL SECURITY;
CREATE POLICY tenant_isolation ON schools USING (id = app_school_id());

GRANT USAGE ON SCHEMA public TO app_user;
GRANT SELECT ON schools TO app_user;
GRANT EXECUTE ON FUNCTION app_school_id() TO app_user;
```

```sql
CREATE TABLE classes (
  id uuid PRIMARY KEY,
  school_id uuid NOT NULL REFERENCES schools (id),
  name text NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (school_id, id),

CREATE TABLE students (
  id uuid PRIMARY KEY,
  school_id uuid NOT NULL REFERENCES schools (id),
  class_id uuid NOT NULL,
  external_code text NOT NULL,
  first_name text NOT NULL,
  full_name text,
  dietary_restrictions text,
  active boolean NOT NULL DEFAULT true,
  created_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (school_id, id),
  UNIQUE (school_id, external_code),
  FOREIGN KEY (school_id, class_id) REFERENCES classes (school_id, id)
);

CREATE TABLE guardians (
  id uuid PRIMARY KEY,
  school_id uuid NOT NULL REFERENCES schools (id),
  phone_e164 text NOT NULL CHECK (phone_e164 ~ '^\+[1-9][0-9]{7,14}$'),
  first_name text NOT NULL,
  email text,
  created_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (school_id, id),
  UNIQUE (school_id, phone_e164)
);

CREATE TABLE guardian_students (
  school_id uuid NOT NULL REFERENCES schools (id),
  guardian_id uuid NOT NULL,
  student_id uuid NOT NULL,
  restriction_consent_at timestamptz,
  PRIMARY KEY (school_id, guardian_id, student_id),
  FOREIGN KEY (school_id, guardian_id) REFERENCES guardians (school_id, id),
  FOREIGN KEY (school_id, student_id) REFERENCES students (school_id, id)
);

CREATE TABLE staff_users (
  id uuid PRIMARY KEY,
  school_id uuid NOT NULL REFERENCES schools (id),
  email text NOT NULL UNIQUE CHECK (email = lower(email)),
  role text NOT NULL CHECK (role IN ('admin', 'secretaria', 'cozinha')),
  active boolean NOT NULL DEFAULT true,
  created_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (school_id, id)
);

CREATE TABLE audit_log (
  id uuid PRIMARY KEY,
  school_id uuid NOT NULL REFERENCES schools (id),
  actor_kind text NOT NULL CHECK (actor_kind IN ('guardian', 'staff', 'kitchen', 'system')),
  actor_id uuid,
  action text NOT NULL,
  detail jsonb NOT NULL DEFAULT '{}',
  created_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (school_id, id)
);

DO $$
DECLARE t text;
BEGIN
  FOREACH t IN ARRAY ARRAY['classes', 'students', 'guardians', 'guardian_students', 'staff_users', 'audit_log']
  LOOP
    EXECUTE format('ALTER TABLE %I ENABLE ROW LEVEL SECURITY', t);
    EXECUTE format('CREATE POLICY tenant_isolation ON %I USING (school_id = app_school_id())', t);
    EXECUTE format('GRANT SELECT, INSERT, UPDATE, DELETE ON %I TO app_user', t);
  END LOOP;
END $$;

REVOKE UPDATE, DELETE ON audit_log FROM app_user;
```

```ts
import cookie from "@fastify/cookie";
import Fastify, { type FastifyInstance } from "fastify";
import { ZodError } from "zod";
import { DomainError } from "./platform/errors";

export type RouteAuth =
  | "public"
  | "internal"
  | { kind: "guardian" | "staff" | "kitchen"; scope?: string; roles?: string[] };

declare module "fastify" {
  interface FastifyContextConfig {
    auth?: RouteAuth;
  }
  interface FastifyRequest {
    rawBody?: string;
  }
}

export function buildApp(): FastifyInstance {
  const app = Fastify({
    logger: {
      level: process.env.LOG_LEVEL ?? (process.env.VITEST ? "silent" : "info"),
      redact: ["req.headers.authorization", "req.headers.cookie", "req.headers['x-signature']"],
    },
  });

  app.register(cookie);

  app.addContentTypeParser("application/json", { parseAs: "string" }, (req, body, done) => {
    const text = body as string;
    req.rawBody = text;
    if (text === "") return done(null, undefined);
    try {
      done(null, JSON.parse(text));
    } catch {
      const err = new Error("invalid json") as Error & { statusCode: number };
      err.statusCode = 400;
      done(err);
    }
  });

  app.addHook("onRoute", (route) => {
    if (!route.config?.auth) {
      throw new Error(`route ${String(route.method)} ${route.url} must declare config.auth`);
    }
  });

  app.addHook("onSend", async (req, reply) => {
    if (req.url.startsWith("/api/")) reply.header("cache-control", "private, no-store");
  });

  app.setErrorHandler((err, req, reply) => {
    if (err instanceof DomainError) {
      return reply.status(err.status).send({ error: { code: err.code, message: err.message } });
    }
    const status = (err as { statusCode?: number }).statusCode;
    if (err instanceof ZodError || (typeof status === "number" && status >= 400 && status < 500)) {
      return reply
        .status(err instanceof ZodError ? 400 : (status as number))
        .send({ error: { code: "validation_failed", message: "invalid request" } });
    }
    req.log.error({ err: { name: (err as Error).name, message: (err as Error).message } }, "unhandled error");
    return reply.status(500).send({ error: { code: "internal_error", message: "internal error" } });
  });

  app.get("/healthz", { config: { auth: "public" } }, async () => ({ ok: true }));

  return app;
}
```

```ts
import { createHmac, timingSafeEqual } from "node:crypto";
import type { FastifyRequest } from "fastify";
import { config } from "./config";
import { DomainError } from "./errors";

const MAX_SKEW_MS = 5 * 60_000;

export function signInternal(secret: string, timestamp: string, body: string): string {
  return createHmac("sha256", secret).update(`${timestamp}\n${body}`).digest("hex");
}

function safeEqual(a: string, b: string): boolean {
  const ab = Buffer.from(a);
  const bb = Buffer.from(b);
  return ab.length === bb.length && timingSafeEqual(ab, bb);
}

function header(req: FastifyRequest, name: string): string {
  const value = req.headers[name];
  return typeof value === "string" ? value : "";
}

/** Lança invalid_signature se a requisição não vier do n8n. */
export function verifyInternalRequest(req: FastifyRequest): void {
  const { internalServiceToken, internalHmacSecret } = config();
  const timestamp = header(req, "x-timestamp");
  const skew = Math.abs(Date.now() - Date.parse(timestamp));
  const expected = signInternal(internalHmacSecret, timestamp, req.rawBody ?? "");
  const ok =
    safeEqual(header(req, "authorization"), `Bearer ${internalServiceToken}`) &&
    Number.isFinite(skew) &&
    skew <= MAX_SKEW_MS &&
    safeEqual(header(req, "x-signature"), expected);
  if (!ok) throw new DomainError("invalid_signature");
}
```

```ts
/** Grava o evento na mesma transação da mudança de estado que o originou. */
export async function enqueueEvent(trx: Trx, schoolId: string, event: OutboxEvent): Promise<string> {
  const parsed = OutboxEvent.parse(event);
```

```ts
import { ErrorResponse } from "@app-lanche/contracts";
import type { z } from "zod";

export class ApiError extends Error {
  constructor(
    public readonly status: number,
    public readonly code: string,
  ) {
    super(code);
  }
}

export async function apiFetch<T>(
  path: string,
  schema: z.ZodType<T>,
  init: { method?: string; body?: unknown } = {},
): Promise<T> {
  let res: Response;
  try {
    res = await fetch(path, {
      method: init.method ?? "GET",
      credentials: "same-origin",
      headers: init.body === undefined ? {} : { "content-type": "application/json" },
      body: init.body === undefined ? undefined : JSON.stringify(init.body),
    });
  } catch {
    throw new ApiError(0, "network_error");
  }
  const json: unknown = await res.json().catch(() => null);
  if (!res.ok) {
    const parsed = ErrorResponse.safeParse(json);
    throw new ApiError(res.status, parsed.success ? parsed.data.error.code : "internal_error");
  }
  return schema.parse(json);
}
```
